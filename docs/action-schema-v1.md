# Action Schema Version 1 — Superseded Draft

Version 1 was implemented as an unactivated design draft. Architecture review
found that it represented several complete Hansa decisions as intermediate
route, city, shape, and displacement selections.

Version 1 was never connected to the production mask, dispatcher, saves,
replays, histories, checkpoints, or trained models. It must not be activated.

The corrected atomic design is documented in
[`action-schema-v2.md`](action-schema-v2.md).
